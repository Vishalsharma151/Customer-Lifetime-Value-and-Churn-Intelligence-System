## 📌 Project Overview

An end-to-end data science project focused on understanding customer churn and building a foundation for customer lifetime value (CLV) analysis and retention strategies using the IBM Telco Customer Churn dataset.

## ✅ Today's Progress — October 21, 2026

- Connected Python to PostgreSQL using SQLAlchemy.
- Loaded customer data into a Pandas DataFrame.
- Inspected dataset dimensions, column names, and data types.
- Checked missing values and duplicate records.
- Converted `TotalCharges` to a numeric data type.
- Analyzed overall churn rate and customer distribution.
- Explored numerical statistics, customer tenure, and monthly charges by churn status.
- Created visualizations using Matplotlib and Seaborn.

## 🛠️ Tech Stack

- Python
- PostgreSQL and SQL
- Pandas and NumPy
- SQLAlchemy
- Matplotlib and Seaborn
- Jupyter Notebook

## 📊 Dataset

**IBM Telco Customer Churn Dataset**

The dataset contains customer demographics, subscribed services, contract details, billing information, tenure, and churn status.
