# Notebook 05 — SHAP Model Explainability

## 1. Overview

This notebook explains the predictions made by the LightGBM churn prediction model using **SHAP (SHapley Additive exPlanations)**.

The objective is to understand which customer features influence churn predictions, identify the most important churn drivers, and explain individual customer predictions.

SHAP helps make the CHURNIQ system more interpretable by showing how model features contribute to predictions.

## 2. Objectives

- Load the trained LightGBM pipeline.
- Load the test dataset used for model evaluation.
- Transform the test features using the fitted preprocessing steps.
- Calculate SHAP values for the transformed features.
- Identify the most influential features across customers.
- Visualize feature importance and the direction of feature contributions.
- Explain an individual customer's prediction.
- Export SHAP values and feature importance results for further analysis.

## 3. Input Files

The notebook uses the following files:

| File | Purpose |
|---|---|
| `../models/churniq_lightgbm_pipeline.joblib` | Previously trained LightGBM pipeline |
| `../models/X_test.csv` | Test features for explainability analysis |

The saved pipeline ensures that the same fitted preprocessing and prediction logic are reused during SHAP analysis.

## 4. SHAP Methodology

SHAP assigns each feature a contribution value that describes how it influences a model prediction relative to an appropriate baseline.

### Global Explainability

Global analysis examines patterns across multiple customers to identify features that have the greatest overall influence on model predictions.

### Local Explainability

Local analysis examines an individual customer's prediction to understand which features push the model output higher or lower.

For binary churn classification, the interpretation depends on the SHAP explainer's output space and the class being explained. A positive SHAP value should not automatically be interpreted as a higher churn probability unless the output scale and explained class support that interpretation.

## 5. Visualizations

The notebook generates the following explainability plots:

- **SHAP Feature Importance:** Ranks features by their average absolute SHAP values.
- **SHAP Summary (Beeswarm) Plot:** Shows the distribution of feature contributions across customers, including their direction and magnitude.
- **Individual Customer Waterfall Plot:** Breaks down the contributions that move a customer's prediction away from the baseline.

These visualizations help identify important churn-related patterns and explain individual predictions.

## 8. Business Value

SHAP explainability supports the CHURNIQ project's business goals by helping stakeholders:

- Identify influential churn-related customer characteristics.
- Understand why a customer receives a particular prediction.
- Investigate patterns that may inform retention strategies.
- Communicate model behavior more transparently.
- Support further analysis of customer retention opportunities.

**Important:** SHAP describes how the trained model uses features to make predictions. It does not establish that a feature causes customer churn, and its explanations should be interpreted alongside business context.
